\# 淘宝电商用户行为分析项目

> 数据集来自阿里云天池公开淘宝用户行为数据集，模拟真实电商业务分析流程。



\## 项目介绍

基于千万级淘宝用户行为数据集抽样样本，完成电商用户行为分析：流量漏斗转化、用户活跃度分层、复购分析、时段\&类目分析，输出业务分析报告。



\## 技术栈

\- MySQL：SQL完成多维度指标提取

\- Python：Pandas数据清洗处理，Matplotlib可视化



\## 文件目录

\- `sample\_user\_behavior.csv`：抽样源数据

\- `\*.csv`：SQL导出的各维度结果数据集

\- `taobao\_analysis.ipynb`：完整分析代码

\- `电商用户行为分析报告.md`：项目分析报告



\## 执行流程

1\. 数据导入MySQL，数据清洗：过滤异常时间戳脏数据

2\. SQL查询提取：漏斗UV、日UV、小时分布、用户活跃区间、复购统计、类目统计

3\. 导出结果CSV，Python读取做计算与可视化

4\. 指标解读，输出业务问题与运营建议



\## 核心业务指标

\- 转化漏斗：浏览‑意向‑支付转化

\- 用户分层：一次性/低活/中活/高活用户

\- 复购率：复购用户 / 总支付用户

\- 用户活跃时段、热门类目统计



\## 关键清洗点

原始数据集存在少量损坏timestamp，解析后会产生异常未来时间，分析时过滤非业务周期样本，保证分析可靠。
